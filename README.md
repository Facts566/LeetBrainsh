# LeetBrainsh 🧠

<img width="120" height="120" alt="icon" src="https://github.com/user-attachments/assets/00ac63da-cd16-4f20-b89b-f13660c99f76" />

**LeetBrainsh** — это интерактивная обучающая игра, созданная для изучения эзотерического языка программирования **Brainsh** (модифицированной версии Brainfuck). 

Вдохновленная Duolingo и LeetCode, игра предлагает систему уровней, где игроки пишут код для решения головоломок, вывода нужных строк и понимания основ низкоуровневого программирования.

## 🚀 Особенности

*   **Интерактивный редактор кода:** Пишите и запускайте код на Brainsh прямо в игре.
*   **Собственный интерпретатор:** Полноценный интерпретатор Brainsh, написанный с нуля на C#.
*   **Прогрессия уровней:** Проходите испытания возрастающей сложности (от простого вывода текста до циклов и математики).
*   **Локализация:** Доступна на русском, английском, испанском, французском, немецком языках.
*   **Робот-маскот:** Потому что каждому хорошему обучающему приложению нужен талисман!

## 🧠 Что такое Brainsh?

Brainsh — это эзотерический язык программирования, основанный на Brainfuck, но с добавлением удобных команд для работы с числами.

**Основные команды можно посмотреть в репозитории языка.**

## 🛠️ Технологии

*   **Движок:** Unity 2022.3
*   **Язык:** C# (для игровой логики и интерпретатора)
*   **Интерфейс:** Unity UGUI
*   **Собственный интерпретатор Brainsh** (написан с нуля)

## 🎮 Как играть

1. Скачайте последний релиз (или соберите проект самостоятельно).
2. Прочитайте задание на экране.
3. Напишите ваш код на Brainsh в поле ввода.
4. Нажмите **Ready** и проверьте, прошел ли ваш код тест!

## 🏗️ Как собрать проект

1. Склонируйте этот репозиторий.
2. Откройте проект в Unity 2022.3 или новее.
3. Перейдите в `File -> Build Settings` и соберите проект под нужную платформу (Android, WebGL или PC).
